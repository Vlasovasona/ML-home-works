### :bar_chart: ML homeworks
<hr>

Репозиторий содержит файлы с выполнением домашних работ по майнору [Интеллектуальный анализ данных](https://electives.hse.ru/minor_intel) ВШЭ Москва. 

Курс проводится для студентов 2-3 курса и содержит следующие дисциплины:
1. Введение в программирование на Python.
2. Основы машинного обучения.
3. Основы глубинного обучения.
4. Прикладные задачи анализа данных.
